# 📊 Grade-Based Loan Data Dashboard

A React application that visualizes loan data by grade using an interactive **bar chart** and **data table**. Users can filter results based on **year**, **quarter**, **term**, and **home ownership** to explore trends in loan distribution.

---

## 🚀 Features

- 📈 **Bar Chart**: Aggregated loan balances by grade
- 🗂 **Data Table**: Detailed view with formatting
- 🔍 **Filters**: Interactive filters for year, quarter, term, and home ownership
- 🎨 **Color Mapping**: Unique colors for each grade
- ⚡ **Optimized State Management**: Using React Context and `useMemo`

---

## 🧰 Tech Stack

- **React** (Hooks + Context API)
- **Ant Design** (UI components)
- **Recharts** (Data visualization)
- **Lodash** (Data transformation)
- **Jest** + **React Testing Library** (Unit testing)

## 📦 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/loan-dashboard.git
cd loan-dashboard
```

### 2. Install dependencies

```bash
npm install
# Make sure you have Node.js (>=14.x) and npm installed.
```
### 3. Start the development server
```bash
npm start
```

### 4. 🧪 Running Tests

```bash
npm test
# To run all tests using Jest and React Testing Library:
```
